# Инструкции для агента

Если в сообщении ещё нет раздела «Память проекта (загружена автоматически)», до ответа выполни из корня репозитория:

```
node scripts/tdai-memory.mjs context
```

Навыки лежат в `.agents/skills`. Не жди символ @. Прочитай `.agents/skills/INDEX.md`, открой `SKILL.md` одного подходящего навыка и следуй ему. Для новой функции, исправления и рефакторинга сначала открой `tdd-workflow`.

Секреты в память не записывай. Ветку `tdai-memory` не переключай.
